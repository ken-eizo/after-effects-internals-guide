# EXP-SHAPE-039 — Native owner / Effect Parade admissibility AEX

This experiment adds an independent x64 AEGP built from the public AE25.6 SDK: `CNLNativeOwnerAdmission.aex`. Unlike private TDB registration experiments, it uses only AEGP dynamic-stream queries.

The user can choose an ordinary AV layer or native Shape Layer and invoke `Animation > CNL Native Owner: Inspect Admission (Read Only)`. The plugin traverses a bounded 240-node/4-depth native group tree. It reports `AEGP_GetMatchName`, grouping type, child count and `AEGP_CanAddStream` results for unknown `ADBE Vector Shape - CNL Probe`, built-in Shape Group, Fill, Trim, Slider Control, and `CNL Native Independent Group`. It creates/deletes/changes nothing and does not call private BEE/TDB code.

Build: Visual Studio 2022 x64 Release succeeded. PE validator passed: x64 DLL, exported EntryPointFunc, PiPL emitted, no direct BEE/TDB imports, forbidden mutation methods absent from source. SHA256, size and source-level validation: `datasets/ae-native-owner-admission-aex-build-20261012.json`. The final binary is `ShapeLayerAE/build/native_owner_admission/Release/CNLNativeOwnerAdmission.aex`, and its full source is mirrored under `experiments/vector-shape/native-owner-admission-lab`.

**Status: NO REAL AE TEST**. It is suitable only as a user-controlled optional read-only investigation. It is NOT evidence of registered custom types, standalone Contents, editing or VectorArt rendering. Logged CanAdd booleans do not certify stream constructibility.

Follow-up validation should compare the exact TSV produced by an ordinary AV layer, an AV layer carrying a standard effect, and a native Shape Layer. This will test the product-relevant boundary identified by FLT::CanStore (F-VECTOR-039) without touching the dangerous registrar. No new Mask or Shape Layer is generated by the AEX.
