# Research Notes

This section records individual investigations, negative results,
changing hypotheses and follow-up experiments. It is intentionally
different from the subsystem architecture chapters.

UI System pages explain host interfaces, state ownership and general
contracts without a specific sample's performance numbers.
The research/findings registry contains one independently testable
statement per file, with scoped evidence and counterexamples.
The experiments directory holds raw logs, checksums, test scripts
and original research narratives.

Research Notes document what was tried and how the interpretation
changed; a transient screenshot counter cannot establish actual
physical monitor presentation or universal host behavior.
